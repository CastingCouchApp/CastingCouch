# Installer

Der MSI-Installer installiert ausschließlich die Anwendung.

Twitch-, Spotify- und OBS-Zugangsdaten werden nicht während der Installation
abgefragt. Sie werden später innerhalb der Anwendung unter Einstellungen
hinterlegt und sicher über Windows DPAPI gespeichert.

Vor einem Verkauf noch erforderlich:

- vollständige Dateierfassung des Publish-Ordners
- Code-Signing-Zertifikat
- finaler Herstellername
- EULA und Datenschutz
- Upgrade-/Rollback-Tests
- optionale Desktop-Verknüpfung
