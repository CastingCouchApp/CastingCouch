# Creator Control Suite 2.0.131

## Free three-zone dashboard layout
- Added real Left, Center and Right dashboard zones.
- Dashboard modules can be dragged between all three zones while layout edit mode is active.
- Module order is stored together with its zone and restored on the next start.
- Every module receives a context menu for moving it left, center or right.
- Every module can be hidden from its context menu.
- Added “Alle Module einblenden” to restore hidden dashboard modules.
- Existing module size settings and layout edit mode remain available.
- The reference dashboard remains the intended default visual direction while the layout itself is user-configurable.
