# Creator Control Suite 2.4.1

- Streamqualität ist jetzt direkt in die Dashboard-Kachel „Stream Status“ integriert.
- Die separate Streamqualitäts-Kachel wurde entfernt; Systemressourcen nutzen den frei gewordenen Platz.
- Unter Dienste > Spotify kann für die gewählte Playlist eine zufällige Songwiedergabe aktiviert werden.
- Beim Start einer Playlist setzt die Suite den Spotify-Shuffle-Zustand über die Spotify Web API, bevor die Wiedergabe beginnt.
