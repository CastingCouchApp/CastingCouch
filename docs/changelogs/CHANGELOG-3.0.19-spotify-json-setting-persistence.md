# Creator Control Suite 3.0.19

## Spotify-JSON-Einstellung gespeichert

- Der Schalter **„Spotify-Daten in JSON schreiben“** wird jetzt aus den gespeicherten Einstellungen geladen.
- Änderungen am Schalter werden sowohl beim allgemeinen Speichern als auch beim Speichern der Spotify-Anzeigeoptionen übernommen.
- Der Schalter wird nicht mehr bei jedem Start zwangsweise zurückgesetzt oder ausgeblendet.
- Ist der Schalter deaktiviert, werden keine Spotify-Laufzeitdaten in die Overlay-JSON geschrieben.
- Die Option **„Bei stummgeschalteter Musik ausblenden“** bleibt unverändert erhalten.
