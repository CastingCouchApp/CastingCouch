# Creator Control Suite 8.0.0-alpha12

## Remote Update anwenden und Rollback

- Update-Status des Remote-Agenten abrufbar.
- Bereitgestellte Pakete können kontrolliert angewendet werden.
- Vor dem Austausch wird ein vollständiges Rollback-Backup erzeugt.
- Rollback kann aus der Suite heraus gestartet werden.
- Optionaler Neustart der Creator Control Suite nach dem Update.
- Update und Rollback werden über ein externes Skript ausgeführt, damit gesperrte Programmdateien nach Beenden des Agenten ersetzt werden können.
- Neue Berechtigung `updates.apply`.
- Agent- und LAN-Version auf 8.0.0-alpha12 aktualisiert.
