# Creator Control Suite 8.0.0-alpha30

## Spotify-Automationsprofile mit Verzögerung und Fade

- Spotify-Aktionen können pro Automatisierungsregel um 0 bis 3600 Sekunden verzögert werden.
- Lautstärkeänderungen können weich über 0 bis 120 Sekunden eingeblendet werden.
- Playlist-Starts setzen bei aktivem Fade zunächst die Lautstärke auf 0 und blenden anschließend bis zur Ziel-Lautstärke ein.
- Auch „Wiedergabe fortsetzen“ und „Lautstärke setzen“ unterstützen den weichen Übergang.
- Die neuen Werte werden dauerhaft in den Automatisierungsregeln gespeichert und beim Duplizieren übernommen.
