# Creator Control Suite 2.0.135

## Fully granular dashboard modules
- Replaced the large dashboard layout groups with 31 independently movable dashboard cards.
- Stream control, OBS scene control and raid control are now separate modules.
- Workflow and preflight are separate modules.
- Scene shortcuts and the OBS audio mixer are separate modules.
- Twitch chat, Twitch users, Twitch events and Spotify are separate modules.
- OBS, Twitch, Spotify, Streamer.bot, Alerts and Overlay quick actions are separate modules.
- Stream statistics, system resources, raid assistant, notifications, Stream Deck/remote, advanced shortcuts and stream history are separate modules.
- Each module can independently move between Left, Center and Right, be reordered, hidden and restored.
- Added persisted per-module minimum width and minimum height values so controls remain readable and are not clipped.
- The old group hosts remain only as internal XAML layout hosts and are no longer persisted as movable dashboard modules.
