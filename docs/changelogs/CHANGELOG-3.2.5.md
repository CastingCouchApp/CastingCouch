# Creator Control Suite 3.2.5

- Spotify-Overlay reagiert sofort auf 0 % Lautstärke.
- Beim Erhöhen über 0 % wird das Overlay sofort wieder eingeblendet.
- Die Option „Bei stummgeschalteter Musik ausblenden“ wird beim Aktivieren unmittelbar angewendet.
- Sichtbarkeit wird sowohl in overlay-data.json als auch – falls konfiguriert – an der OBS-Quelle aktualisiert.
- Verzögerte oder fehlende Spotify-Gerätelautstärke verhindert die Funktion nicht mehr.
