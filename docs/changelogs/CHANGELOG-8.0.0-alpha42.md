# Creator Control Suite 8.0.0-alpha42

## Spotify-Zustandsverlauf: Export und Import

- Verlauf und Sitzungsstatistik können als formatierte JSON-Datei exportiert werden.
- Export enthält Formatversion, Exportzeitpunkt, Statistikzähler und bis zu 100 Verlaufseinträge.
- Ein zuvor exportierter Verlauf kann wieder importiert werden.
- Import prüft Formatversion und Dateistruktur und begrenzt den Verlauf weiterhin auf 100 Einträge.
- Fehler und erfolgreiche Aktionen werden in der Automationsdiagnose angezeigt.
- Neue Schaltflächen: `VERLAUF EXPORTIEREN` und `VERLAUF IMPORTIEREN`.
