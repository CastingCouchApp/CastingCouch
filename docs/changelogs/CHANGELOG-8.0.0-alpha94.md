# Creator Control Suite 8.0.0-alpha94

## Twitch Professional – Phase 5

- Schnellwahl für Timeouts: 1, 10, 60 und 1.440 Minuten.
- Neues Moderationsprotokoll direkt im Twitch-Dienstbereich.
- Erfolgreiche und fehlgeschlagene Ban-/Timeout-Aktionen werden nachvollziehbar protokolliert.
- Aufhebungen von Ban und Timeout werden ebenfalls protokolliert.
- Dauerhaftes lokales Log unter `%LocalAppData%\CreatorControlSuite\Logs\twitch-moderation.log`.
- Export des Moderationsprotokolls als datierte Textdatei.
- Protokollansicht kann geleert werden, ohne die dauerhafte Logdatei zu löschen.
