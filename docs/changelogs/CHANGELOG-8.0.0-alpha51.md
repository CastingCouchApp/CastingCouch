# Creator Control Suite 8.0.0-alpha51

## Spotify-Zustandsverlauf – detaillierter Backup-Vergleich

- Konkrete Liste der Eintragsunterschiede zwischen ausgewählter Sicherung und aktuellem Verlauf.
- Kennzeichnung: hinzukommend, wird ersetzt oder unverändert.
- Automatische Aktualisierung bei Auswahl oder manueller Vorschau.
- Begrenzte, übersichtliche Darstellung mit Hinweis auf weitere ausgeblendete Einträge.
- Vorschaufehler erscheinen auch direkt in der Vergleichsliste.
