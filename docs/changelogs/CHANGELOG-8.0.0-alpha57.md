# Creator Control Suite 8.0.0-alpha57

## Spotify-Verlauf – Importregeln pro Wiederherstellungsprofil

- Konflikte beim Profilimport können jetzt einzeln aufgelöst werden.
- Für geänderte Profile stehen **Überschreiben**, **Als Kopie importieren** und **Überspringen** bereit.
- Neue Profile können importiert oder übersprungen werden.
- Unveränderte Profile bleiben automatisch auf Überspringen.
- Kopien erhalten automatisch einen eindeutigen Namen, ohne vorhandene Profile zu verändern.
- Importstatus und Diagnoseprotokoll unterscheiden neue, überschriebene und als Kopie importierte Profile.
