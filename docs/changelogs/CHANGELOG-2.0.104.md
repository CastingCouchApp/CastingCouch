# Creator Control Suite 2.0.104

## Reorderable dashboard modules
- Major dashboard sections can now be reordered.
- Added drag-and-drop ordering in Settings → Dashboard.
- Added Move Up and Move Down buttons as an accessible alternative.
- Added Reset Order action.
- Module order is persisted in AppSettings and restored on startup.
- Missing or newly introduced dashboard modules are automatically normalized into the saved order.
- Existing show/hide module settings continue to work together with the saved order.
- Layout changes are applied immediately without restarting the suite.

This is the first persistent free-layout layer. The next step can add resizing and finer card-level placement on top of the same saved dashboard configuration.
