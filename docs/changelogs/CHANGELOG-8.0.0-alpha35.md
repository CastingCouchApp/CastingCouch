# Creator Control Suite 8.0.0-alpha35

## Spotify-Automationen: automatische Rückkehr

- Gesicherte Spotify-Wiedergabe kann nach einer frei wählbaren Dauer automatisch wiederhergestellt werden.
- Neue Option „Vorherige Wiedergabe automatisch wiederherstellen“ pro Automatisierungsregel.
- Rückkehrzeit zwischen 1 Sekunde und 24 Stunden.
- Die Rückkehr nutzt weiterhin den konfigurierten Fade und den gruppenbezogenen Wiedergabezustand.
- Ein neuer gleich- oder höher priorisierter Spotify-Befehl kann die wartende Rückkehr abbrechen.
- Exklusive Gruppen bleiben während der zeitgesteuerten Aktion geschützt.
- Fehlende Sicherungszustände werden verständlich in den Automatisierungsdiagnosen protokolliert.
