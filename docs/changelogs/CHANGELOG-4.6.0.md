# Creator Control Suite 4.6.0

## Twitch Professional Integration – Phase 1

- Twitch-Moderation verwendet jetzt die offizielle Helix-Moderations-API statt Chatbefehlen.
- Frei einstellbare Timeout-Dauer in Minuten.
- Optionaler Moderationsgrund bis 500 Zeichen.
- Direkter Ban.
- Ban oder Timeout direkt aufheben.
- Twitch-Benutzer werden vor der Moderation über die API aufgelöst.
- Schutz vor Moderation des eigenen Kanals.
- Neuer OAuth-Scope `moderator:manage:banned_users`. Bestehende Twitch-Autorisierungen müssen einmal erneuert werden.
