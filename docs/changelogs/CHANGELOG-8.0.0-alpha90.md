# Creator Control Suite 8.0.0-alpha90

## Twitch Professional – Phase 1

- Neue zentrale Live-Analyse im Twitch-Dienstbereich.
- Anzeige von Live-/Offline-Status, aktueller Zuschauerzahl, Peak und Durchschnitt.
- Anzeige der beobachteten Live-Dauer.
- Lokale Session-Zähler für Chatnachrichten, aktive Chatter und Twitch-Events.
- Anzeige des Follower-Zuwachses der aktuellen Stream-Session.
- Streamtitel und Kategorie werden gemeinsam mit den Live-Kennzahlen dargestellt.
- Manuelle Aktualisierung der Twitch-Professional-Ansicht.
- Session-Zähler werden beim Start einer neuen Stream-Session zurückgesetzt.
- UI-Aktualisierungen sind Dispatcher-sicher und reagieren auf Chat-, Event-, Viewer- und Workflow-Aktualisierungen.
