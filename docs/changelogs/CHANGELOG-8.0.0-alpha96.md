# Creator Control Suite 8.0.0-alpha96

## Creator Intelligence Core – Phase 1

- Neue lokale, asynchrone Ereignisdatenbank unter `%LocalAppData%\CreatorControlSuite\CreatorIntelligence`.
- Gemeinsame Session-Aufzeichnung für Twitch-Zuschauerwerte, Chat, Follows und allgemeine Twitch-Ereignisse.
- OBS-Szenenwechsel werden mit Zuschauerzahl und Zeitstempel korreliert.
- Spotify-Titelwechsel werden mit Szene und Zuschauerzahl gespeichert.
- Freie Session-Notizen können während eines Streams gespeichert werden.
- Begrenzte Ereigniswarteschlange verhindert unkontrollierten Speicherverbrauch bei langen Streams.
- Automatische lokale Session-Auswertung nach Streamende.
- Creator Score von 0 bis 100.
- Kennzahlen für Zuschauerbindung, Chataktivität und Follower-Wachstum.
- Regelbasierte, aus den eigenen Sessiondaten erzeugte Verbesserungshinweise.
- Neues Creator-Intelligence-Panel im professionellen Twitch-Bereich.
- Datenordner kann direkt aus der Suite geöffnet werden.
