# Creator Control Suite 2.1.1

## Korrekturen
- Aktive Reiter werden suiteweit orange mit schwarzer Schrift dargestellt.
- Hover- und deaktivierte Zustände der Reiter vereinheitlicht.
- Lokale Tab-Farben entfernt, damit der aktive Stil zuverlässig greift.
- Spotify-Lautstärkeregler unter Dienste auf 420 px begrenzt.
- Spotify-Lautstärke wird während des Ziehens live übertragen.
- Kurzes 60-ms-Debouncing verhindert unnötig viele Spotify-API-Aufrufe.
- Laufende veraltete Lautstärkeaufrufe werden abgebrochen.
