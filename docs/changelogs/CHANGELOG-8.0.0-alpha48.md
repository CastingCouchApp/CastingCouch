# Creator Control Suite 8.0.0-alpha48

## Spotify-Verlaufssicherungen

- Automatische Wiederherstellungspunkte vor dem Überschreiben der lokalen Spotify-Verlaufshistorie.
- Automatische Sicherungen werden auf höchstens eine Sicherung je 30 Minuten begrenzt.
- Es werden maximal zehn Sicherungen aufbewahrt; ältere Dateien werden automatisch entfernt.
- Manueller Button zum sofortigen Erstellen eines Wiederherstellungspunktes.
- Neueste Sicherung kann direkt aus der Suite wiederhergestellt werden.
- Sicherungsordner kann direkt im Windows-Explorer geöffnet werden.
- Sicherungs- und Wiederherstellungsfehler werden in der Automationsdiagnose und im Statusbereich angezeigt.
- Sicherungen liegen unter `%LocalAppData%\CreatorControlSuite\Backups\SpotifyHistory`.
