# Creator Control Suite 8.0.0-alpha49

## Spotify-Zustandsverlauf – Backup-Verwaltung

- Neue Liste aller vorhandenen Verlaufssicherungen, neueste zuerst.
- Anzeige von Datum, Uhrzeit, Dateigröße und vollständigem Speicherpfad.
- Ausgewählte Sicherung kann gezielt wiederhergestellt werden.
- Vor einer Wiederherstellung wird der aktuelle Verlauf automatisch gesichert.
- Ausgewählte Sicherungen können nach Sicherheitsabfrage gelöscht werden.
- Sicherungsliste kann manuell aktualisiert werden und aktualisiert sich nach Erstellen, Löschen und Wiederherstellen automatisch.
- Diagnosemeldungen für Wiederherstellung und Löschung ergänzt.
