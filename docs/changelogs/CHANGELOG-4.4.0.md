# Creator Control Suite 4.4.0 – Visual Workflow Designer

- Neuer Reiter „Workflow-Designer“ für Automatisierungsgruppen.
- Graphische Darstellung von Regeln als verschiebbare Knoten.
- Erfolgspfade und Fehlerpfade werden getrennt visualisiert.
- Knotenpositionen werden dauerhaft in den Einstellungen gespeichert.
- Auto-Layout für große Workflow-Gruppen.
- Zoom zwischen 50 % und 200 %.
- Live-Statusfarbe anhand des letzten Regelstatus.
- Graphprüfung auf doppelte Reihenfolgen und ungültige Verbindungen.
- Bestehende Automatisierungen bleiben kompatibel.
