# Creator Control Suite 8.0.0-alpha1

## Multi-PC Foundation

- Neue Navigation **Multi-PC**.
- Lokaler Hauptrechner wird als aktiver Agent angezeigt.
- Geräte können mit Name, Host/IP und einmaligem Pairing-Code registriert werden.
- Persistente Geräteliste unter `%LOCALAPPDATA%/CreatorControlSuite/multi-pc-devices.json`.
- Erreichbarkeitsprüfung registrierter Geräte per Ping.
- Live-Zähler für Geräte und erreichbare Rechner.
- Automatische Aktualisierung alle fünf Sekunden.
- Geräte können wieder aus der Registrierung entfernt werden.

## Abgrenzung dieser Alpha

Die Version stellt die echte Geräteverwaltung und Netzwerk-Erreichbarkeitsprüfung bereit. Verschlüsselte Agent-Kommunikation, Remote-Befehle und Dateisynchronisation folgen in weiteren 8.x-Ausbaustufen.
