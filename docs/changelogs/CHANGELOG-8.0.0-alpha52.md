# Creator Control Suite 8.0.0-alpha52

## Spotify – selektive Wiederherstellung von Verlaufssicherungen

- Sicherungsbereiche können unabhängig voneinander wiederhergestellt werden:
  - Verlaufseinträge
  - Favoriten
  - Notizen
  - Statistikzähler
  - Such-, Filter- und Sortiereinstellungen
- Verlaufseinträge können wahlweise zusammengeführt oder vollständig ersetzt werden.
- Beim Zusammenführen bleiben vorhandene Einträge erhalten; doppelte Einträge werden vermieden.
- Favoriten und Notizen werden nur für tatsächlich vorhandene Verlaufseinträge übernommen.
- Vor jeder selektiven Wiederherstellung wird automatisch ein Wiederherstellungspunkt erstellt.
- Sicherheitsabfrage zeigt die konkret ausgewählten Bereiche an.
- Status und Automationsdiagnose protokollieren Ergebnis oder Fehler.
