# Creator Control Suite 2.0.105

## Direct dashboard layout editing
- Added Layout bearbeiten button directly to the dashboard header.
- Edit mode allows major dashboard sections to be moved directly via drag and drop.
- Active edit mode uses a move cursor and visual feedback.
- Layout speichern exits edit mode and persists the current order.
- Direct dashboard ordering stays synchronized with Settings → Dashboard.
- The existing settings-based drag-and-drop and arrow controls remain available.
- The saved order is restored on the next application start.

The dashboard is now directly rearrangeable without opening Settings first.
