# Creator Control Suite 8.0.0-alpha86

## Spotify Phase 6 – Geräteautomatik

- Spotify-Standardgerät kann direkt aktiviert werden.
- Optional wird das Standardgerät vor dem Start einer Playlist automatisch übernommen.
- Optional wird bei nicht erreichbarem Standardgerät ein aktives, steuerbares Ersatzgerät verwendet.
- Eingeschränkte Geräte werden mit einer verständlichen Fehlermeldung abgewiesen.
- Gerätestatus zeigt die automatische Übernahme sichtbar an.
- Neue Einstellungen werden dauerhaft gespeichert.
