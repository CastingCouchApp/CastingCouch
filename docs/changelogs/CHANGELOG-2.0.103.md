# Creator Control Suite 2.0.103

## Configurable dashboard modules
- Added a dedicated Dashboard tab under Settings.
- Users can show or hide major dashboard sections independently.
- Configurable sections: service status cards, stream controls, live Twitch/Spotify panels, quick services, workflow rail, advanced tools, notification/remote section and stream history.
- Dashboard layout selection is persisted in AppSettings.
- Added Apply Layout and Reset to Standard actions.
- Layout is applied immediately without restarting the suite.
- This is the first stable configuration layer for the later drag-and-drop dashboard editor.
