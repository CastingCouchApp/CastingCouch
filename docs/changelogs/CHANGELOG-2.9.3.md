# Creator Control Suite 2.9.3

## Regieplan – automatischer Ablauf

- Regieschritte können nach einer frei einstellbaren Wartezeit automatisch zum nächsten aktiven Schritt wechseln.
- Der automatische Ablauf kann gestartet und jederzeit gestoppt werden.
- Einzelne Schritte können als bewusste Pause im Regieplan dienen.
- Während der Wartezeit wird ein sichtbarer Countdown angezeigt.
- Deaktivierte Schritte werden automatisch übersprungen.
- Zurücksetzen beendet eine laufende Automatik sicher.
- Der Ablauf startet und beendet keinen OBS-Stream.
