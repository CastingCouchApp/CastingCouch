# Creator Control Suite 8.0.0-alpha29

## Spotify-Szenenautomationen

- Zeit- und Szenenautomationen können jetzt eine Spotify-Playlist starten.
- Playlist-URI wird pro Automationsregel gespeichert.
- Shuffle kann pro Regel aktiviert oder deaktiviert werden.
- Fehlende Playlist-URIs werden mit einer verständlichen Fehlermeldung abgefangen.
- Bestehende Aktionen Pause, Fortsetzen und Lautstärke bleiben unverändert verfügbar.
