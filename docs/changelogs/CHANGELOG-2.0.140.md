# Creator Control Suite 2.0.140

## Fixed reference dashboard
- Dashboard modules are no longer movable.
- Fixed reference arrangement:
  - Stream Status | Current OBS Scene | Quick Access
  - Services | Spotify | Twitch Chat
  - Next Automations | Live Events | System Resources
- Fixed row heights and proportional widths modeled on the approved reference screenshot.
- Existing functional WPF controls were moved into the fixed layout, preserving their existing event handlers.
- Stream preparation, stream start/end, test alert, overlay access, OBS scene switching, service actions, Spotify controls and Twitch chat remain connected to the existing logic.
- Direct dashboard dragging and layout-edit activation are disabled.
- Legacy advanced dashboard sections remain hidden for compatibility.
