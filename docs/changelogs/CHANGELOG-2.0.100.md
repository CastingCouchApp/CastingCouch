# Creator Control Suite 2.0.100

## Functional dashboard OBS audio mixer
- Added a compact OBS audio mixer directly to the dashboard.
- Audio input list is populated from the live OBS snapshot.
- Selected source shows current mute state and volume in dB.
- Mute and unmute can be controlled directly from the dashboard.
- Volume can be set directly in dB with OBS-compatible limits.
- Errors and successful mixer actions are routed through the Notification Center.
- The full OBS services mixer remains available through the existing quick-access button.
