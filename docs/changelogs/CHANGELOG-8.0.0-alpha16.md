# Creator Control Suite 8.0.0-alpha16

## Rollout-Gruppen und Canary-Sicherheit

- Remote-PCs können dauerhaft Rollout-Gruppen zugeordnet werden.
- Updates lassen sich auf eine ausgewählte Gruppe begrenzen.
- Konfigurierbare Anzahl an Canary-Geräten wird zuerst aktualisiert.
- Fehler in der Canary-Phase stoppen den weiteren Rollout automatisch.
- Konfigurierbare maximale Fehlerquote für automatische Stopps.
- Live-Zusammenfassung für bearbeitete, erfolgreiche und fehlgeschlagene Geräte.
- Gruppen werden unter `%LOCALAPPDATA%\\CreatorControlSuite\\multi-pc-rollout-groups.json` gespeichert.
