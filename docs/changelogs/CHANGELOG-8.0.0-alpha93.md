# Creator Control Suite 8.0.0-alpha93

## Twitch Professional – Phase 4

- Neuer automatisch erzeugter HTML-Stream-Report mit Gesamtwerten und den letzten 50 Sessions.
- Kopierbare Kurz-Zusammenfassung des zuletzt abgeschlossenen Streams.
- Neue Kennzahlen für Engagement pro Stunde, Follower pro Stunde und Zuschauer-Konstanz.
- Report enthält Titel, Kategorie, Dauer, Peak, Durchschnitt, Follower und Chataktivität.
- Beste Kategorie wird im Report anhand des Zuschauerdurchschnitts bewertet.
- Reports werden im bestehenden lokalen Stream-Historienordner gespeichert und direkt geöffnet.
