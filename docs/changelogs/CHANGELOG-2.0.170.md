# Creator Control Suite 2.0.170

- Overlay-Ordner kann über eine Ordnerauswahl gewählt werden.
- Bereits laufende Programme, insbesondere Streamer.bot, werden bei der Streamvorbereitung nicht erneut gestartet.
- Dashboard-Szenenauswahl zeigt nach OBS-Verbindung alle in OBS vorhandenen Szenen.
- OBS-Szenenvorschau wird im Sekundentakt aktualisiert.
- Streamvorbereitung setzt den Start-Countdown im Overlay auf den konfigurierten Ausgangswert zurück.
