# Creator Control Suite 8.0.0-alpha38

## Spotify-Zustandsübersicht

- Zentrale Übersicht aller gespeicherten Spotify-Automationszustände ergänzt.
- Pro Gruppe werden Titel, Interpret, Position, Lautstärke und Wiedergabestatus angezeigt.
- Ausgewählte Zustände können direkt aus der Übersicht wiederhergestellt oder verworfen werden.
- Alle gespeicherten Zustände lassen sich gemeinsam leeren.
- Die Übersicht aktualisiert sich nach Speichern, Wiederherstellen und Verwerfen automatisch.
- Sämtliche manuellen Aktionen werden weiterhin in der Automationsdiagnose protokolliert.
