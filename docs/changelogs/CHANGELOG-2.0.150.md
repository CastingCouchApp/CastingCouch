- Increased all three dashboard row heights.
- Reduced gaps between dashboard modules to one pixel.
- Forced all visible cards to stretch to the full width and height of their grid cells.
- Enlarged the Twitch Chat area and its message list.
- Enlarged Automation and Live Events lists to close lower-row empty spaces.
- Reduced internal card padding so Services, Spotify, Twitch Chat and lower modules use their available space more efficiently.
