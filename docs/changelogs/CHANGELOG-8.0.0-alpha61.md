# Creator Control Suite 8.0.0-alpha61

## Build-Stabilisierung III

- Fehlende Namespaces für JSON-HTTP-Erweiterungen und ZIP-Dateierstellung ergänzt.
- Zentrale UI-Aktionsausführung (`ExecuteUiActionAsync`) wiederhergestellt.
- Einheitliche Fehleranzeige und Protokollierung (`ShowError`) wiederhergestellt.
- Vertrauenswürdigen Agent-Client als kompatible Weiterleitung ergänzt.
- Fehlende Spotify-Felder in `RunOfShowStepSettings` ergänzt.
- Nullability-Fehler bei der Auswahl einer Spotify-Verlaufssicherung korrigiert.

Hinweis: In der Erstellungsumgebung stand kein .NET SDK für einen vollständigen Build zur Verfügung.
