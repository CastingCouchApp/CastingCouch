# Creator Control Suite 8.0.0-alpha20

## Spotify-Wiederholungssteuerung

- Neuer Wiederholungsbutton im Spotify-Dashboard.
- Drei Modi: Aus, Playlist/Kontext wiederholen und aktuellen Titel wiederholen.
- Der aktive Spotify-Wiederholungsstatus wird direkt aus der Web API gelesen.
- Abgelaufene Zugriffstokens werden auch bei der Wiederholungssteuerung automatisch erneuert.
- Buttontext und Tooltip zeigen den aktuell aktiven Modus an.
