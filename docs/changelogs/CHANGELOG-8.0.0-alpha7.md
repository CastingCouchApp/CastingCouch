# Creator Control Suite 8.0.0-alpha7

## Remote OBS Sources, Volume and Sync

- Szenen-Items der aktuellen Programmszene werden über den Agenten geladen.
- Quellen können remote ein- und ausgeblendet werden.
- Lautstärke einer OBS-Audioquelle kann remote in dB gesetzt werden.
- Optionaler automatischer OBS-Statusabgleich im 5-Sekunden-Takt.
- Remote-Status enthält Szenen, Audioquellen, Pegel, Mute-Zustand und Sichtbarkeit der aktuellen Szenen-Items.
- Neue TLS-geschützte Endpunkte: `/api/obs/volume` und `/api/obs/scene-item`.
