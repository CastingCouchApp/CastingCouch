# Creator Control Suite 2.1.0

- Overlay-Bereich zum Overlay-Designer ausgebaut.
- Neue Standardszene Reactions.
- Reactions-Content: Titel, frei platzierbarer Webcam-/Content-Rahmen und Hinweistext.
- Rahmenarten und Animationen erweitert: gepunktet, Neon, Glas, 3D, Pulsieren, Atemeffekt, Farbwechsel, Regenbogen, Lauflicht, Blinken, Zoom-Puls und Schatten.
- Farbpalette mit Farbvorschau und zusätzlichem HEX-Feld.
- Starttimer-Felder eindeutig mit Countdown-Zeit, Position X und Position Y beschriftet.
- OBS-Import vollständiger Szenen strikt vom ausgewählten Overlay-Pfad getrennt.
- Einzelne Texte, Timer, Spotify, Streamstats und Rahmen werden nur über Einzelnes Element eingefügt.
- Mitgelieferte Beispielsets Modern, Minimal und Neon mit sechs Szenen integriert.
