# Creator Control Suite 3.0.11

- Spotify-Anzeigeoptionen werden beim Anklicken sofort gespeichert und in die aktive overlay-data.json geschrieben.
- `hideWhenPaused` wird nicht mehr fest auf `true` überschrieben.
- Spotify-HTML-Kompatibilitätspatch unterstützt nun spotify.html und spotify-info.html sowie verschiedene Elementnamen.
- Twitch-Alert-Ereignisse aktivieren automatisch das externe Alert-Ducking für Streamer.bot-Alerts.
- OBS-Szenenautomation initialisiert die aktuell aktive Szene auch ohne vorherigen Szenenwechsel.
- OBS-Regeln werden bei jeder erneuten Aktivierung ihrer Szene wieder freigegeben und genau einmal ausgeführt.
