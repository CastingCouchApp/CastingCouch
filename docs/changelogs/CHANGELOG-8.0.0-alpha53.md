# Creator Control Suite 8.0.0-alpha53

## Spotify-Verlauf: Wiederherstellungsprofile

- Drei integrierte Profile: nur Verlauf zusammenführen, Verlauf plus Favoriten, alles vollständig ersetzen.
- Eigene Kombinationen aus Verlauf, Favoriten, Notizen, Statistik, Filter/Sortierung und Zusammenführungsmodus speicherbar.
- Eigene Profile werden dauerhaft unter LocalAppData gespeichert und beim Start geladen.
- Vorhandene eigene Profile können überschrieben oder gelöscht werden.
- Integrierte Profile sind vor versehentlichem Löschen geschützt.
- Status- und Diagnosemeldungen für Laden und Speichern ergänzt.
