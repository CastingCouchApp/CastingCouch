# Creator Control Suite 4.3.0 – Workflow Groups & Rollback

## Neu
- Automatisierungsregeln können über einen frei wählbaren Gruppennamen zu einem Workflow zusammengefasst werden.
- Reihenfolge pro Gruppenschritt.
- Eine Regel kann beim Auslösen die gesamte Gruppe starten.
- Fehlerverhalten pro Workflow: stoppen, fortfahren oder Rückabwicklung starten.
- Jedem Schritt kann eine separate Rückabwicklungsregel zugeordnet werden.
- Rückabwicklung erfolgt in umgekehrter Reihenfolge der bereits abgeschlossenen Schritte.
- Eindeutige Workflow-Lauf-ID in der Diagnose.
- Import/Export erhält Rückabwicklungs-Verknüpfungen.
- Validierung für fehlende Gruppen und ungültige Rückabwicklungsregeln.
