# Creator Control Suite 8.0.0-alpha26

## Spotify-Playlistbrowser

- Eigene Spotify-Playlists können nach Name oder Besitzer gefiltert werden.
- Bis zu 50 Titel der ausgewählten Playlist können direkt geladen werden.
- Playlist-Titel lassen sich sofort abspielen oder zur Warteschlange hinzufügen.
- Das bevorzugte Spotify-Gerät und die automatische Token-Erneuerung werden weiter verwendet.
- Die vorhandene Playlist-Startfunktion und Shuffle-Option bleiben erhalten.
