# Creator Control Suite 2.9.2

## Regieplan: Twitch-Kanalaktionen

- Jeder Regieschritt kann optional den Twitch-Streamtitel aktualisieren.
- Twitch-Kategorien können direkt im Regieplan gesucht und ausgewählt werden.
- Kategorie-ID und Anzeigename werden dauerhaft gespeichert.
- Titel und Kategorie können gemeinsam oder einzeln geändert werden.
- Optional kann der Regieplan bei einem Twitch-Fehler fortgesetzt werden.
- Twitch-Aktionen werden separat unter `RunOfShow.Twitch` protokolliert.
- OBS, Spotify und Streamer.bot bleiben unverändert kombinierbar.
- Der Regieplan startet oder beendet weiterhin keinen echten Stream.
