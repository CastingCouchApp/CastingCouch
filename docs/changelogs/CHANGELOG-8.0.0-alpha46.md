# Creator Control Suite 8.0.0 Alpha 46

## Spotify-Zustandsverlauf: Favoriten und Notizen

- Einzelne Verlaufseinträge können als Favorit markiert und wieder aus den Favoriten entfernt werden.
- Neuer Filter „Nur Favoriten“.
- Für einen ausgewählten Verlaufseintrag kann eine eigene mehrzeilige Notiz gespeichert oder durch Leeren entfernt werden.
- Die Detailansicht zeigt den Favoritenstatus und lädt die zugehörige Notiz.
- Die Suche berücksichtigt zusätzlich gespeicherte Notizen.
- JSON-Exporte verwenden Formatversion 2 und sichern Favoriten sowie Notizen.
- Auswahlexporte enthalten nur Favoriten und Notizen der ausgewählten Einträge.
- Der Import unterstützt weiterhin Formatversion 1 und zusätzlich Formatversion 2.
- CSV-Exporte enthalten die neuen Spalten „Favorit“ und „Notiz“.
- Beim Entfernen oder Leeren von Verlaufseinträgen werden zugehörige Favoriten und Notizen ebenfalls entfernt.
