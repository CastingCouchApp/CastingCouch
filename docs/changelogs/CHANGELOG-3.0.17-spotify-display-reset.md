# Creator Control Suite 3.0.17

## Spotify-Anzeige zurückgesetzt

- Die einzelnen Optionen zum Ausblenden von Titel, Interpret, Album-Cover und Fortschritt wurden entfernt.
- Titel, Interpret, Album-Cover und Fortschritt werden wieder grundsätzlich an das Overlay übergeben.
- Eine Pause blendet das Spotify-Modul nicht mehr aus.
- Als einzige Sichtbarkeitsoption bleibt „Bei stummgeschalteter Musik ausblenden“ erhalten.
- Stummschaltung wird über eine Spotify-Gerätelautstärke von 0 % erkannt.
- Die OBS-Browserquelle wird bei Wiedergabe- und Lautstärkeupdates entsprechend synchronisiert.
