# Creator Control Suite 2.0.108

## Dashboard module size presets
- Major dashboard sections now support three persistent size presets: Kompakt, Standard and Groß.
- Size presets can be changed under Settings → Dashboard for the selected module.
- During direct dashboard edit mode, clicking a module selects it for sizing.
- Direct size selector is shown in the dashboard header while edit mode is active.
- Module size changes are saved in AppSettings and restored on startup.
- Size presets work together with module visibility and saved module order.
- Compact and Standard use constrained dashboard widths; Groß uses the full available command-center width.
