# Creator Control Suite 8.0.0-alpha37

## Spotify-Automation: gespeicherte Zustände manuell verwalten

- Neuer Statusbereich im Automationseditor für den aktuell gewählten Spotify-Gruppenzustand.
- Zeigt Titel, Interpret, Wiedergabeposition, Lautstärke, Shuffle, Repeat und Play/Pause an.
- Gespeicherter Zustand kann sofort manuell wiederhergestellt werden.
- Die manuelle Wiederherstellung verwendet die eingestellte Fade-Dauer.
- Eine laufende oder wartende Spotify-Automation wird dabei kontrolliert abgebrochen.
- Gespeicherte Zustände können gezielt verworfen werden.
- Alle manuellen Aktionen erscheinen in der Automationsdiagnose.
