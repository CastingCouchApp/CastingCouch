# Creator Control Suite 8.0.0-alpha43

## Spotify-Zustandsverlauf: Filter, Suche und CSV-Export

- Freitextsuche für Gruppe, Aktion und Verlaufsinhalt ergänzt.
- Aktionsfilter für gespeichert, wiederhergestellt, verworfen und bereinigt ergänzt.
- Filter können mit einem Klick zurückgesetzt werden.
- Statusanzeige nennt sichtbare und gesamte Einträge bei aktivem Filter.
- CSV-Export ergänzt; exportiert bewusst nur die aktuell gefilterte Ansicht.
- CSV-Dateien werden UTF-8 mit BOM und deutsch-kompatibler Semikolon-Trennung geschrieben.
- JSON-Export und -Import bleiben unverändert verfügbar.
- CSV-Erfolge und Fehler werden in der Automationsdiagnose protokolliert.
