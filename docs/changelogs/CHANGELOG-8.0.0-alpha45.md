# Creator Control Suite 8.0.0-alpha45

## Spotify-Zustandsverlauf: Mehrfachauswahl und Sammelaktionen

- Der Verlauf unterstützt jetzt Mehrfachauswahl mit Strg und Umschalt.
- Alle aktuell sichtbaren beziehungsweise gefilterten Einträge können gemeinsam ausgewählt werden.
- Die Auswahl kann separat als JSON oder CSV exportiert werden.
- Mehrere ausgewählte Verlaufseinträge können gemeinsam entfernt werden.
- Die Detailansicht zeigt bei Mehrfachauswahl die Anzahl der gewählten Einträge.
- Sammelaktionen liefern verständliche Status- und Diagnosemeldungen.
- Der bestehende vollständige JSON-Export und der gefilterte CSV-Export bleiben erhalten.
