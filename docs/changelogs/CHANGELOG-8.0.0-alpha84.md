# Creator Control Suite 8.0.0-alpha84

## Spotify-Ausbau – Phase 4

- Neuer Bereich „Gespeicherte Titel (Gefällt mir)“ unter Dienste → Spotify.
- Bis zu 200 gespeicherte Spotify-Titel werden geladen.
- Gespeicherte Titel können direkt abgespielt werden.
- Einzelne Titel können aus der Spotify-Bibliothek entfernt werden.
- Der aktuell laufende Titel kann direkt gespeichert oder wieder entfernt werden.
- Favoritenliste wird nach Änderungen automatisch aktualisiert.
- Neue Spotify-Berechtigungen `user-library-read` und `user-library-modify` ergänzt.

## Hinweis

Nach dem Update Spotify einmal trennen und neu autorisieren, damit die neuen Bibliotheksrechte erteilt werden.
