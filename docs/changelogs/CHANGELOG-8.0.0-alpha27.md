# Creator Control Suite 8.0.0-alpha27

## Spotify – Playlist-Favoriten und Schnellstart

- Playlists können unter Dienste → Spotify als Favorit markiert oder wieder entfernt werden.
- Die fünf zuletzt gestarteten Playlists werden dauerhaft gespeichert.
- Favoriten und zuletzt verwendete Playlists stehen als gemeinsame Schnellstartliste zur Verfügung.
- Die Schnellstartliste ist sowohl auf dem Dashboard als auch auf der Spotify-Dienste-Seite verfügbar.
- Gestartete Playlists werden automatisch an den Anfang der Zuletzt-verwendet-Liste gesetzt.
