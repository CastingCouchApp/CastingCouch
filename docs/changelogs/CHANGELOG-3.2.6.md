# Creator Control Suite 3.2.6

## Spotify-Overlay

- Spotify-Anzeige wird bei 0 % Lautstärke zuverlässig ausgeblendet.
- Externes Stummschalten in Spotify wird nach dem nächsten Statusabruf erkannt.
- Alert-Ducking auf 0 % blendet das Spotify-Overlay ebenfalls aus.
- Nach dem Aufheben der Stummschaltung wird das Overlay automatisch wieder eingeblendet.
- Kurzzeitige Verzögerungen der Spotify Web API überschreiben eine gerade in der Suite gesetzte Lautstärke nicht mehr.
