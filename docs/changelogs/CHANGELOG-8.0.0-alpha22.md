# Creator Control Suite 8.0.0-alpha22

## Spotify: Titelsuche im Dashboard

- Die bisherige Spotify-Fortschrittsanzeige im Dashboard ist jetzt bedienbar.
- Ein Klick auf die Zeitleiste springt direkt zur gewählten Position im aktuellen Titel.
- Die neue Spotify-Seek-Anfrage nutzt das bevorzugte Wiedergabegerät und erneuert abgelaufene Tokens automatisch.
- Die Zeitleiste bleibt bei automatischen Playback-Aktualisierungen synchron.
