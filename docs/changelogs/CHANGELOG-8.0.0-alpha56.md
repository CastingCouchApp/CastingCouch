# Creator Control Suite 8.0.0 Alpha 56

## Spotify-Verlauf – selektive Konfliktauflösung beim Profilimport

- Neue und geänderte Wiederherstellungsprofile können in der Importvorschau einzeln ausgewählt werden.
- Änderbare Profile sind standardmäßig aktiviert.
- Unveränderte Profile werden deaktiviert angezeigt und nicht erneut importiert.
- Der Import bricht mit einem verständlichen Hinweis ab, wenn kein Profil ausgewählt ist.
- Nicht ausgewählte Profile werden beim Übernehmen übersprungen.
- Die Importvorschau zeigt Status, Profilname und enthaltene Wiederherstellungsbereiche direkt neben der Auswahl.
