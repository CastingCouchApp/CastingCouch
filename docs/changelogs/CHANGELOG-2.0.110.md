# Creator Control Suite 2.0.110

## Stream focus mode
- Added a dedicated Focus Mode button to the dashboard.
- Focus Mode temporarily rearranges the dashboard for live operation.
- It prioritizes service status, stream controls, Twitch/Spotify live panels, OBS tools and workflow state.
- Less important sections such as history and secondary quick-service panels are temporarily hidden.
- Exiting Focus Mode restores the exact previous module order, visibility and size settings.
- Added optional automatic Focus Mode activation when the stream starts.
- Added optional automatic exit when the stream ends.
- Automatic behavior can be configured under Settings → Dashboard.
- Focus Mode is temporary and does not overwrite the user's normal saved dashboard layout.
