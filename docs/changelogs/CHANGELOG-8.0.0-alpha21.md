# Creator Control Suite 8.0.0-alpha21

## Spotify-Steuerung im Dienste-Bereich

- Shuffle kann jetzt auch unter **Dienste → Spotify** direkt ein- und ausgeschaltet werden.
- Der Wiederholungsmodus kann dort zwischen **Aus**, **Playlist** und **Titel** umgeschaltet werden.
- Beide Schaltflächen zeigen jederzeit den von Spotify gemeldeten aktuellen Zustand.
- Dashboard und Dienste-Seite bleiben nach jeder Änderung synchron.
