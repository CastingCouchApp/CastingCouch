# Creator Control Suite 2.0.92

## Command Center expansion
- Added functional preflight checklist and workflow stage indicator.
- Added configured scene shortcut buttons for Start, Live/Game, Pause/Metaschutz and End.
- Added dashboard access to the OBS mixer, profiles, workflow, diagnostics, settings and services.
- Added raid-assistant refresh action.
- Added a dashboard notification center for workflow/preflight feedback.
- Added Stream Deck / remote-control management shortcut.
- Existing Twitch, Spotify, OBS, Streamer.bot, alert, profile and workflow functionality remains available.

## Important
Some larger roadmap items (full historical analytics database, drag-and-drop dashboard editor and a dedicated local remote-control API) require separate persistence/API subsystems and are not represented as completed merely by dashboard buttons.
