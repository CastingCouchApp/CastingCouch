# Creator Control Suite 8.0.0-alpha85

## Spotify-Ausbau – Phase 5

- Spotify-Automatik um sichtbare Stream-Lebenszyklusoptionen erweitert.
- Startplaylist kann beim Streamstart automatisch gestartet werden.
- Dieselbe Playlist kann beim Wechsel in die Endszene als Endmusik gestartet werden.
- Spotify kann nach dem tatsächlichen OBS-Streamende automatisch pausiert werden.
- Einstellungen werden im bestehenden Spotify-Automatikbereich gespeichert.
- Fehler beim Starten der Endmusik oder Pausieren blockieren das Streamende nicht und werden als Dashboard-Warnung angezeigt.
