# Creator Control Suite 6.1.0

## Stream Deck Professional Integration – Phase 9

- Automatische Profil- und Seitenumschaltung anhand von Stream-, OBS- und Spotify-Zuständen
- Zeitregeln im Format HH:mm
- Prioritäten von 0 bis 1000; die höchste passende Regel gewinnt
- Verzögerte Ausführung von 0 bis 3600 Sekunden
- Fallback-Regeln für Situationen ohne passende Hauptregel
- Persistente Regeln in `streamdeck-automation-rules.json`
- Automatische Prüfung alle fünf Sekunden und manuelle Sofortprüfung
- Aktiver Zustand wird mit Regel-ID und Ursache in `streamdeck-state.json` dokumentiert
