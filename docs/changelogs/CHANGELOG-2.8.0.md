# Creator Control Suite 2.8.0

## OBS und Automatisierung
- OBS-Übergänge werden über WebSocket geladen und sind in der Automatisierung auswählbar.
- Szenenlisten behalten vorhandene Auswahlwerte.
- Quellen werden abhängig von der gewählten Szene geladen.
- Fehler beim Laden von Quellen werden sichtbar statt still verworfen.

## Stream-Kurztest
- Eigener Assistent unter Automatisierung.
- Prüft OBS, Spotify, Streamer.bot und overlay.json ohne einen Stream zu starten.
- Optionale Tests für Suite-Alerts und Automatisierungsregeln.
- Ergebnisliste mit Einzelstatus.

## Spotify API Inspector
- Filter nach GET, Schreibzugriffen, Fehlern und OAuth.
- Bis zu 100 sichtbare Detailaufrufe.
- Zusammenfassung der tatsächlichen Methoden/Aktionsarten.
