# Creator Control Suite 2.0.95

## Dashboard stream profiles
- Existing profile subsystem is now directly available in the dashboard.
- Dashboard profile selector lists all saved Creator Control Suite profiles.
- One-click action applies the selected profile, reloads its settings and immediately runs Stream vorbereiten.
- Profile application progress and errors are shown in the workflow status and notification center.
- Profile list is loaded on application startup and refreshed together with the existing profile management page.

This turns profiles into practical stream modes: users can maintain separate settings for GTA RP, Just Chatting, Poker or other stream types and prepare the selected setup from the dashboard.
