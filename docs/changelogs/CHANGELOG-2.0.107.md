# Creator Control Suite 2.0.107

## Automatic Twitch event statistics
- Twitch EventSub events now feed the running stream session statistics automatically.
- Tracks new subscriptions and resubscription events.
- Tracks gifted subscription counts.
- Tracks cheered Bits.
- Tracks incoming raids.
- Alert-producing Twitch events increment the session alert counter.
- Dashboard session metrics update immediately after Twitch events.
- New Twitch metrics are persisted in stream history.
- Statistics table includes Subs, Gift-Subs and Bits for stored sessions.
- Overlay session statistics model exposes the new counters for end-scene/statistics widgets.
