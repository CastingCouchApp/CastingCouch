# Creator Control Suite 8.0.0-alpha41

## Spotify-Zustandsstatistik und Verlauf

- Neue Sitzungsstatistik für gespeicherte Spotify-Wiedergabezustände.
- Zählt Speichern, Wiederherstellen, manuelles Verwerfen und automatische Bereinigungen getrennt.
- Zeigt zusätzlich die aktuell vorhandene Anzahl gespeicherter Zustände.
- Neuer Verlauf mit Uhrzeit und Spotify-Gruppe.
- Der Verlauf erfasst Einzelaktionen, Sammelverwerfen und automatische Bereinigungen.
- Die letzten 100 Einträge bleiben während der Programmsitzung sichtbar.
- Neuer Button zum Leeren des Verlaufs; die Statistikzähler bleiben dabei erhalten.
