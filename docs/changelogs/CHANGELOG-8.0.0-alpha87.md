# Creator Control Suite 8.0.0-alpha88

## Spotify Phase 7 – Mini-Player und Dashboard

- Dashboard zeigt Wiedergabestatus und aktives Spotify-Gerät.
- Eingeschränkte, nicht fernsteuerbare Geräte werden sichtbar gekennzeichnet.
- Play/Pause-Schaltflächen spiegeln den aktuellen Zustand wider.
- Transporttasten werden nur aktiviert, wenn Spotify sinnvoll steuerbar ist.
- Dashboard-Fortschrittsregler wird ohne laufenden Titel deaktiviert.
- Albumcover werden nur bei einem tatsächlichen Coverwechsel erneut geladen.
- Unnötige HTTP-Aufrufe und sichtbares Cover-Flackern werden dadurch reduziert.
