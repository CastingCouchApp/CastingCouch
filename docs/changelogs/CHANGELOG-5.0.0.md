# Creator Control Suite 5.0.0

## Streamer.bot Professional Control – Phase 2

- frei definierbare JSON-Parameter für manuell ausgeführte Aktionen
- Detailansicht mit Aktions-ID, Gruppe und Aktivstatus
- Favoritenmarkierung für häufig verwendete Aktionen
- Favoriten werden in der Aktionsliste bevorzugt angezeigt
- Ausführungshistorie der letzten 20 Aktionen
- Status, Uhrzeit, Laufzeit oder Fehlermeldung je Ausführung
- Historie kann direkt in der Streamer.bot-Zentrale geleert werden
- JSON-Validierung vor dem Senden an Streamer.bot
