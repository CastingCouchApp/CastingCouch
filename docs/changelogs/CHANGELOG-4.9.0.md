# Creator Control Suite 4.9.0

## Streamer.bot Professional Integration – Phase 1

- Neue professionelle Streamer.bot-Zentrale.
- Aktionen nach Name oder Gruppe suchen.
- Aktionen neu aus Streamer.bot laden.
- Ausgewählte Aktionen direkt ausführen.
- Anzeige von Aktionsname, Gruppe, ID und Aktivstatus.
- WebSocket-Diagnose mit Antwortzeit, Aktionsanzahl und Event-Listener-Status.
- Verbesserte Verbindungs- und Fehleranzeigen.
- Vorhandene Alert-Ducking-, Run-of-Show- und Automatisierungsfunktionen bleiben erhalten.
