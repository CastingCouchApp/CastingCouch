# Creator Control Suite 2.0.96

## Persistent stream statistics
- Added a dedicated Statistik page to the main navigation.
- Reads the existing local stream history and aggregates all saved sessions.
- Summary cards show total streams, total streaming time, weighted average viewers, best peak, gained followers and average stream duration.
- Session table shows date, duration, average viewers, peak viewers, follower gain, category and title.
- Category analysis shows stream count, hours and average viewers per category.
- Development view shows the latest 20 streams in chronological order with average viewers, peak and follower gain.
- Statistics refresh automatically after a completed stream and can also be refreshed manually.
- Direct button opens the local statistics/history data folder.

The statistics are based on the persisted session history introduced in 2.0.93.
