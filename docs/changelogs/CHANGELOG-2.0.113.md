# Creator Control Suite 2.0.113

## Automatic Twitch goal synchronization
- Added automatic retrieval of the current active Twitch subscription count.
- Follower goal current value is synchronized from the live Twitch follower total.
- Sub goal current value is synchronized from Twitch active subscriptions.
- Goal values refresh after Twitch connection.
- Follow, subscription, resubscription and gift-sub events trigger goal refreshes.
- Dashboard now shows current follower and sub goal progress.
- Existing goal targets, font settings and OBS/overlay source creation remain configurable.
- Overlay data receives the automatically synchronized current values for follower and sub goals.
- Manual target values remain untouched; only current progress values are synchronized automatically.
