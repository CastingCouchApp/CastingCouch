# Creator Control Suite 8.0.0-alpha28

## Spotify-Geräteverwaltung

- Verfügbare Spotify-Wiedergabegeräte können auf der Dienste-Seite gezielt aktualisiert werden.
- Der Gerätestatus zeigt Typ, Aktivstatus, Lautstärke, Einschränkungen und das gespeicherte Standardgerät.
- Wiedergabe kann ausdrücklich auf das ausgewählte Gerät übertragen werden.
- Optional kann die Wiedergabe beim Übertragen sofort gestartet werden.
- Das ausgewählte Gerät kann dauerhaft als bevorzugtes Spotify-Gerät gespeichert werden.
- Ein bloßer Wechsel der ComboBox-Auswahl überträgt die Wiedergabe nicht mehr unbeabsichtigt.
- Geräteabruf erneuert bei abgelaufenem Zugriffstoken automatisch die Spotify-Sitzung.
