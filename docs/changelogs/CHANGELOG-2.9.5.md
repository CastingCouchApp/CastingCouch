# Creator Control Suite 2.9.6

## Mehrere Regiepläne

- Mehrere benannte Regiepläne können parallel gespeichert werden.
- Neuer Regieplan kann direkt auf der Regieplan-Seite erstellt werden.
- Aktiver Regieplan lässt sich über eine Auswahlliste wechseln.
- Regiepläne können umbenannt und gelöscht werden.
- Der letzte verbleibende Regieplan ist vor versehentlichem Löschen geschützt.
- Beim Planwechsel wird eine laufende Regieautomatik sicher beendet.
- Jeder Regieplan besitzt seine eigene Reihenfolge und eigene Schritte.
- Vorhandene Regieschritte aus älteren Versionen werden automatisch in den Plan „Standard“ übernommen.
- Exportdateiname und Exportname verwenden den Namen des aktiven Regieplans.
- Fehlende Persistenzroutine für Regieplanänderungen ergänzt.
