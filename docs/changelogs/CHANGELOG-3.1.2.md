# Creator Control Suite 3.1.2

- Spotify-Lautstärke wird direkt beim OBS-Ereignis Startszene → Game-Szene geregelt.
- Spotify JSON-Export ist dauerhaft aktiviert und kann nicht mehr versehentlich deaktiviert werden.
- Zeitgesteuerte OBS-Regeln werden beim Speichern explizit in den Programmeinstellungen persistiert und nach dem Start wieder geladen; vorhandene Regeln bleiben auswählbar und bearbeitbar.
- Dienste > Streamer.bot zeigt die geladenen Actions in einer eigenen Liste.
- Ausgewählte Reiter verwenden ein festes dunkeloranges Template statt des weißen Windows-Standardzustands.
- Listen und Statistik-Zellen verwenden dunkle Flächen mit lesbarer heller Schrift.
- Ein separater Streamer.bot-Eventkanal erkennt Follow-, Sub-, Cheer-, Raid- und Alert-Ereignisse und löst das Spotify-Ducking aus.
