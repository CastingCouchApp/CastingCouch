# Creator Control Suite 8.0.0-alpha83

## Spotify-Ausbau – Phase 3

- Warteschlangentitel werden als auswählbare Einträge mit Interpret, Titel und Album angezeigt.
- Ausgewählte Warteschlangentitel können sofort abgespielt werden.
- Der aktuell laufende Titel kann direkt im Warteschlangenbereich übersprungen werden.
- Warteschlange und Verlauf werden nach Wiedergabeaktionen automatisch aktualisiert.
- Nach dem Vormerken aus Suche oder Verlauf erscheint der Titel sofort in der Warteschlange.
- Verständliche Statusmeldungen für fehlende Auswahl und ausgeführte Aktionen ergänzt.
- Hinweis: Spotify stellt keine API zum gezielten Löschen oder Umsortieren einzelner Warteschlangeneinträge bereit.
