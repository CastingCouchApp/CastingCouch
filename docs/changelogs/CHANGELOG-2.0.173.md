# Creator Control Suite 2.0.174

- Neues eigenständiges Browserquellen-Modul `stream-stats.html` für die aktuelle Streamsession.
- Anzeige von neuen Followern, neuen Subs, Geschenk-Subs, Peak-Zuschauern, durchschnittlichen Zuschauern und Streamdauer.
- Das Modul ist keiner Standardszene fest zugeordnet.
- Es kann unter Einstellungen → Overlay als einzelnes Content-Modul in jede beliebige OBS-Szene eingefügt werden.
- Position, Größe und Zuschnitt werden anschließend frei in OBS festgelegt.
