# 8.0.0-alpha102-hotfix20

## Streamende-Raid: Sofort-/raid und Countdown überspringen

- Bei Streamende mit Raid-Wunsch wird der Raid-Befehl **sofort** gestartet (Helix StartRaid + Chat `/raid <ziel>`), nicht erst nach der Endszene.
- Die Endszene bleibt sichtbar; die Wartezeit steuert der Raid-Countdown.
- **JETZT RAIDEN** überspringt den lokalen Raid-Countdown und setzt das Streamende fort (Twitch-Raid bleibt aktiv).
- **RAID ABBRECHEN** beendet weiterhin den Twitch-Raid; der Stream bleibt aktiv.
