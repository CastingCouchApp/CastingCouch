# Creator Control Suite 8.0.0-alpha80

## Dashboard-Korrekturen

- Die Kachel **Abonnenten** zeigt jetzt die von Twitch gelieferte Anzahl aktiver Abonnements.
- Chatnachrichten und abgespielte Alerts werden nicht mehr irrtuemlich als Abonnentenverhaeltnis angezeigt.
- Beim Trennen von Twitch wird die Abonnentenzahl auf 0 zurueckgesetzt, statt einen alten Wert stehen zu lassen.
- Das grosse Streamstatus-Badge ist nicht mehr statisch auf LIVE gesetzt.
- Das Badge zeigt nun korrekt LIVE oder OFFLINE und verwendet passend dazu eine rote bzw. graue Darstellung.
- Mindestbreite und zentrierte Beschriftung verhindern eine abgeschnittene Statusanzeige.
