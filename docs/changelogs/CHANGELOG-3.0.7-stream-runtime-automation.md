# Creator Control Suite 3.0.7

- Spotify-Overlay wird bei Pause ausgeblendet.
- Wechsel Start -> Game setzt Spotify auf 75 %.
- Alerts setzen Spotify auf exakt 50 % und stellen danach die vorherige Lautstärke wieder her.
- Beim Streamstart: Start-Szene, 10-Minuten-Timer, Start_Testbild an; nach 5 Minuten aus; nach 10 Minuten Wechsel zu Game.
- OBS-Mikrofon- und Broadcast-Mute werden direkt in die aktive overlay-data.json geschrieben.
- Live-Zuschauerzahl und Streamdauer werden direkt aktualisiert.
- Ende-Statistik wird fortlaufend in die aktive overlay-data.json geschrieben.
- Followerziel wird aus der Suite direkt übernommen und mit der aktuellen Followerzahl aktualisiert.
