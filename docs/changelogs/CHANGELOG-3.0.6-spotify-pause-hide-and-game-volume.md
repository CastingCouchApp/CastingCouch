# Creator Control Suite 3.0.6

- Spotify-Overlay wird bei pausierter Wiedergabe ausgeblendet.
- Die aktive Spotify-Browserquelle in OBS wird ebenfalls deaktiviert, sofern Szene und Quelle konfiguriert sind.
- Beim Szenenwechsel von der konfigurierten Startszene zur konfigurierten Live-/Game-Szene wird Spotify einmalig auf 75 % gesetzt.
- Vorherige Spotify-, Overlay-Data- und OBS-Mute-Fixes bleiben enthalten.
