# Creator Control Suite 3.0.13

- Streamstatistiken werden beim echten OBS-Streamstart vollständig zurückgesetzt.
- Follower-Ausgangswert wird beim Streamstart gespeichert.
- Vor dem Wechsel auf die Endszene werden letzte Zuschauer- und Followerwerte abgerufen.
- Finale Statistiken werden vor Anzeige der Endszene in die aktive overlay-data.json geschrieben.
- Endszene enthält jetzt das vollständige Streamstats-Modul.
- Anzeige: Dauer, Peak, Durchschnitt, neue Follower, Subs, Gift-Subs, Bits, Chatnachrichten, Alerts und eingehende Raids.
- Streamhistorie speichert dieselben finalen Werte dauerhaft.
