# Creator Control Suite 8.0.0-alpha63

## Korrekturen

- Zentrale Projektversion auf `8.0.0-alpha63` angehoben.
- Die zuvor mehrfach hart codierte Agent-Version `8.0.0-alpha18` durch eine zentrale Konstante ersetzt.
