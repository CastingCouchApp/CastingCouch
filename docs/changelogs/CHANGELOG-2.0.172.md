# Creator Control Suite 2.0.172

- Alte Standard-Overlays durch Start, Game, Pause, Metaschutz und Ende ersetzt.
- Neue HTML-Content-Module: Content Name, Szenentext, Starttimer, Spotify-Info, Live/Uhrzeit, Metaschutz-Status, Pausentext und frei konfigurierbarer Rahmen.
- Overlay-Texte, Schriftart, Schriftgröße, Farbe, Timerposition und Rahmen werden in den Einstellungen bearbeitet.
- Szenen und einzelne Content-Module können direkt in OBS eingefügt werden.
