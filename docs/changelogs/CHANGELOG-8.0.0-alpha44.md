# Creator Control Suite 8.0.0-alpha44

## Spotify-Zustandsverlauf: Sortierung und Detailansicht

- Neue Sortierung für den Spotify-Zustandsverlauf:
  - Neueste zuerst
  - Älteste zuerst
  - Aktion A–Z
  - Gruppe A–Z
- Neue Detailansicht für den ausgewählten Verlaufseintrag.
- Details werden getrennt als Zeit, Gruppe und Aktion dargestellt.
- Beim Leeren des Verlaufs wird auch die Detailauswahl zurückgesetzt.
- „Filter zurücksetzen“ stellt zusätzlich die Standardsortierung „Neueste zuerst“ wieder her.
- Filter, JSON-Import/-Export und CSV-Export bleiben vollständig erhalten.
