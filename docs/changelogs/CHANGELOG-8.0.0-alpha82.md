# Creator Control Suite 8.0.0-alpha82

## Spotify-Ausbau – Phase 2

- Fortschrittsregler unter Dienste > Spotify ergänzt.
- Springen an eine frei gewählte Position im aktuellen Titel möglich.
- Aktuelle Position und Gesamtdauer werden direkt am Regler angezeigt.
- Spotify-Suchergebnisse können nun direkt abgespielt werden.
- Vormerken in der Warteschlange bleibt als separate Aktion erhalten.
- Nach Wiedergabe- und Seek-Aktionen wird der Spotify-Zustand sofort neu geladen.
