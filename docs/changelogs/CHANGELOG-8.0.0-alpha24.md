# Creator Control Suite 8.0.0-alpha24

## Spotify-Suche und Warteschlangensteuerung

- Titelsuche nach Titel, Interpret oder Album auf der Spotify-Dienste-Seite ergänzt.
- Suchergebnisse können direkt zur aktiven Spotify-Warteschlange hinzugefügt werden.
- Bevorzugtes Wiedergabegerät wird beim Hinzufügen berücksichtigt.
- Warteschlange wird nach dem Hinzufügen automatisch neu geladen.
- Spotify-Token wird bei einer 401-Antwort automatisch erneuert und der Vorgang wiederholt.
