# Creator Control Suite 3.2.7

## Spotify-Overlay: robuste Mute-Erkennung

- „Bei stummgeschalteter Musik ausblenden“ kann den Mute-Status über die Spotify-Gerätelautstärke und die konfigurierte OBS-Audioquelle erkennen.
- Beide Erkennungswege sind standardmäßig aktiviert.
- Die OBS-Audioquelle ist in Dienste → Spotify auswählbar.
- „Zusätzlich bei pausierter Musik ausblenden“ ist eine separate, standardmäßig deaktivierte Option.
- Mute über OBS-Mixer, Suite oder Automatisierung führt damit zum gleichen Overlay-Verhalten.
