# Creator Control Suite 2.0.136

## Free-flow fixed-size dashboard
- Removed the fixed Left / Center / Right dashboard columns.
- Added one free-flow WrapPanel dashboard surface.
- Modules can be placed next to each other and continue on the next row according to available width.
- Dragging changes the module order/placement without changing its width or height.
- Re-grouped the complete connection status strip as one movable module.
- Re-grouped the service quick-access cards as one movable module.
- Kept functional modules such as stream control, workflow status, preflight, scenes, audio mixer, raid, notifications and history independently movable.
- Fixed width and height are persisted for every dashboard module and applied as Width/MinWidth/MaxWidth and Height/MinHeight/MaxHeight.
- Default module order follows the relationships of the approved dashboard reference.
