# Creator Control Suite 2.7.1

## Spotify API Inspector

- Neuer Tab **Spotify API Inspector** unter **Protokolle**.
- Zeigt die letzten 20 Spotify-Web-API- und OAuth-Aufrufe.
- Anzeige von Uhrzeit, API-Bereich, abgeleitetem Auslöser, Methode/Aktion, Endpunkt, HTTP-Status, Dauer und Retry-After.
- Zähler für API-Aufrufe innerhalb der letzten Minute.
- Letzter Status und letzte Retry-After-Angabe werden hervorgehoben.
- Manuelle Aktualisierung und Kopieren eines ausgewählten Eintrags.
- Aktualisiert sich bei neuen Spotify-Logeinträgen automatisch.
- Access Token, Refresh Token, Client Secret und Autorisierungscodes werden weiterhin nicht angezeigt.
