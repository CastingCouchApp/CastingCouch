# Creator Control Suite 2.0.146

## Stateful dashboard service actions
- OBS, Twitch, Spotify and Streamer.bot dashboard service buttons now toggle between connecting and disconnecting.
- Button text changes automatically between VERBINDEN and TRENNEN based on the real service state.
- Tooltips also reflect the current action.
- The button state refreshes after connect, disconnect, global live refresh and initial window load.
- Disconnecting from the regular service views also updates the dashboard action buttons.
- Existing service status lamps and top status text remain synchronized with the real connections.
