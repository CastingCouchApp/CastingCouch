# Creator Control Suite 2.0.158

- Diensteseiten werden weiterhin über die Navigation gewählt, aber ohne sichtbare Reiter dargestellt.
- Ein Wechsel zu anderen Diensten ist innerhalb der geöffneten Diensteseite nicht mehr möglich.
- Dashboard-Dienstekarten bieten jetzt oben direkt Öffnen sowie Verbinden/Trennen.
- Verbindungsbuttons passen Beschriftung und Tooltip automatisch an den aktuellen Zustand an.
- Oberer Dashboardbereich wurde fest innerhalb der 1670-Pixel-Arbeitsfläche ausgerichtet, damit das Zahnrad vollständig sichtbar bleibt.
- Diensteseiten optisch an das dunkle Dashboard-Farbschema angepasst; Orange deutlich reduziert.
