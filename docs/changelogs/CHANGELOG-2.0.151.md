# Creator Control Suite 2.0.151

## Navigation visibility, active state and dashboard spacing
- Fixed StatisticsPage remaining visible over every subsequently selected page.
- ShowPage now collapses and resets the Z-order of all application pages, including StatisticsPage.
- Removed the permanently hard-coded orange Dashboard state.
- Added dynamic orange highlighting for the currently selected navigation item.
- Szenen & Quellen, Overlays and Stream Deck keep their own active highlight while opening the corresponding real tab.
- Standardized all nine dashboard cell margins to the same value.
- Removed module-level margins that could create uneven spacing.
- Increased the Twitch Chat column width.
- Increased the row height containing Services, Spotify and Twitch Chat.
- Enlarged the Twitch Chat message list and reduced its internal padding.
