# Creator Control Suite 8.0.0-alpha23

## Spotify-Warteschlange

- Spotify-Dienste-Seite zeigt den aktuell laufenden Titel.
- Die nächsten Titel der Spotify-Warteschlange werden aufgelistet.
- Die Warteschlange kann manuell aktualisiert werden.
- Die Daten werden auch bei einer vollständigen Spotify-Aktualisierung geladen.
