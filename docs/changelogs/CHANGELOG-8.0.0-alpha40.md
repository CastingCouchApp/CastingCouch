# Creator Control Suite 8.0.0-alpha40

## Spotify – automatische Bereinigung gespeicherter Zustände

- Abgelaufene Spotify-Zustände können beim Programmstart automatisch entfernt werden.
- Optional erfolgt die Bereinigung vor jedem neuen Speichern eines Wiedergabezustands.
- Eine Intervallbereinigung kann aktiviert und zwischen 1 und 1440 Minuten eingestellt werden.
- Der aktive Bereinigungsintervall wird im Statusbereich angezeigt.
- Diagnoseeinträge unterscheiden zwischen manueller Bereinigung, Programmstart, Speichervorgang und Intervalllauf.
- Leere automatische Prüfungen erzeugen beim Programmstart und vor dem Speichern keine unnötigen Diagnoseeinträge.
