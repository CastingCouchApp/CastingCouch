# Creator Control Suite 2.3.1

## Twitch Chat und Userliste

- EventSub startet jetzt auch dann weiter, wenn einzelne optionale Twitch-Abonnements wegen fehlender Berechtigungen scheitern.
- Der Chat wird dadurch nicht mehr von einem Fehler bei Follows, Subs, Bits, Raids oder anderen Event-Abonnements blockiert.
- Fehlgeschlagene Abonnements erscheinen als verständliche Warnung in der Twitch-Eventliste.
- Eine klare Fehlermeldung wird nur noch ausgegeben, wenn überhaupt kein Chat- oder Event-Abonnement aktiviert werden konnte.
- Eingehende Chatnachrichten scrollen automatisch zur neuesten Nachricht.
- Die Userliste kombiniert die Twitch-API-Liste mit tatsächlich im Chat gesehenen Benutzern.
- Benutzeranzahl wird im Dashboard und auf der Twitch-Dienstseite angezeigt.
- Vorübergehende Fehler beim Laden der Userliste unterbrechen Chat und EventSub nicht.
