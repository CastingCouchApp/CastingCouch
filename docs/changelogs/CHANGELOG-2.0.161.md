# Creator Control Suite 2.0.161

- Twitch-Dienst: verwaltbare Liste häufiger Raidziele mit Hinzufügen und Entfernen.
- Dashboard: sichtbare Streamende-/Raid-Steuerung mit Umschaltung zwischen normalem Streamende und Streamende mit Raid.
- Das ausgewählte Raidziel wird auf Dashboard und Twitch-Seite synchronisiert und dauerhaft gespeichert.
- Online-/Offline-Status, Zuschauerzahl, Kategorie, Streamtitel und Live-Dauer werden vor dem Raid geprüft.
- Der automatische Raid wird nur gestartet, wenn der Zielkanal online ist; anschließend wird der OBS-Stream beendet.
