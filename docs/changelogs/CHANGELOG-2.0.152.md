# Creator Control Suite 2.0.152

## Services submenu navigation and dashboard services consolidation
- Replaced the flat Services navigation with an expandable submenu.
- Services submenu contains Spotify, Twitch, OBS, Streamer.bot and Stream Deck.
- Removed redundant main navigation entries for Scenes & Sources and Stream Deck.
- Service submenu items navigate directly to their real service/settings pages.
- The submenu stays open while a service child is active.
- The top dashboard service-status strip now acts as the dashboard services entry point.
- OBS, Twitch, Spotify and Streamer.bot status labels are clickable and open the matching service page.
- The redundant middle-row Services module is hidden.
- Spotify now spans the first two columns of the middle row; Twitch Chat keeps the full right column.
- Standardized all dashboard cell margins to the same value.
