# Creator Control Suite 2.4.7

- Spotify-Einstellungen auf Verbindung, Programmpfad, Autorisierung und Öffnen von Spotify reduziert.
- Live-Titel, Albumcover und Player-Steuerung bleiben ausschließlich unter Dienste → Spotify.
- HTTP-429-Behandlung liest Retry-After aus und hebt die Sperre automatisch wieder auf.
- Rate-Limit-Meldungen verschwinden nach Ablauf der Wartezeit automatisch.
- Weitere Klicks während der kurzen Sperre erzeugen keine zusätzlichen Popups oder API-Aufrufe.
