# Creator Control Suite 8.0.0-alpha25

## Spotify-Verlauf und Schnellaktionen

- Unter Dienste > Spotify werden die zuletzt gespielten Titel angezeigt.
- Ein ausgewählter Verlaufstitel kann sofort wieder abgespielt werden.
- Ein ausgewählter Verlaufstitel kann direkt zur Warteschlange hinzugefügt werden.
- Der Verlauf kann manuell aktualisiert werden.
- Der Spotify-Scope `user-read-recently-played` wurde ergänzt. Nach dem Update kann eine erneute Spotify-Autorisierung nötig sein.
