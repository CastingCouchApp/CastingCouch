# Creator Control Suite 8.0.0-alpha36

## Spotify-Automation: bedingte automatische Wiederherstellung

- Automatische Rückkehr kann an die weiterhin aktive OBS-Szene gebunden werden.
- Optional wird geprüft, ob dieselbe Spotify-Automationsgruppe noch aktiv ist.
- Optional wird eine manuelle oder externe Änderung von Titel bzw. Wiedergabekontext erkannt.
- Bei nicht mehr erfüllten Bedingungen wird die Wiederherstellung sicher verworfen und diagnostiziert.
- Alle drei Schutzbedingungen sind bei neuen Regeln standardmäßig aktiviert.
