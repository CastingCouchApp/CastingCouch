# Ersteinrichtungs-Assistent – 2.0.81

Der Assistent erscheint beim ersten Start und erfasst:

- Anzeigename
- Twitch-Kanalname
- OBS Host und Port
- Start-, Live-, Pause- und Endszene
- Overlay-Ordner
- Installation des Standard-Overlays

Twitch- und Spotify-Tokens werden nicht während der Installation abgefragt.
