# Creator Control Suite 3.6.0

## Automation Conditions, Chains and Diagnostics

- Optional conditions for OBS connection, Streamer.bot connection, active stream and current OBS scene
- Conditions can be inverted
- Rules can start a following rule after an optional delay
- Rule chains detect and stop loops
- Chains can optionally continue after an action error
- Live diagnostics history for executed, skipped and failed rules
- Full rule validation for missing targets, invalid references and chain loops
- Existing 3.5.0 automation rules remain compatible
