# Creator Control Suite 3.3.2

## OBS Control Center – Produktionssteuerung

- OBS-Übergangsauswahl und Übergangsdauer im Dienste-Bereich sichtbar geschaltet.
- Medienquellen können neu gestartet und gestoppt werden.
- Browserquellen können ohne Cache neu geladen werden.
- Quelltypabhängige Buttons verhindern ungültige Aktionen.
- Audiopegel zeigt zusätzlich einen verständlichen Prozentwert an.
- OBS-WebSocket-Unterstützung für `PressInputPropertiesButton` ergänzt.
