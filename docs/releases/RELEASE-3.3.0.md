# Creator Control Suite 3.3.0

## OBS Control Center

- Die vollständige Szenen-, Quellen- und Audiomixer-Verwaltung im OBS-Dienst ist jetzt sichtbar.
- Szenen, Quellen und Audioeingänge besitzen Suchfelder.
- Die aktive Programmszene wird hervorgehoben und zuerst einsortiert.
- Doppelklick auf eine Szene wechselt direkt zu dieser Szene.
- OBS-Ereignisse aktualisieren Szenen, Quellen und Eingänge ohne dauerhaftes Polling.
- Medienquellen können direkt aus der Quellenverwaltung neu gestartet werden.
- Bestehende Funktionen für Sichtbarkeit, Sperren, Ebenen, Transformationen, Filter, Mute und dB-Lautstärke bleiben erhalten.

## Technische Hinweise

Die OBS-WebSocket-Event-Abonnements wurden um Konfiguration, Szenen, Eingänge, Filter, Ausgaben, Szenenelemente und Medien erweitert.
