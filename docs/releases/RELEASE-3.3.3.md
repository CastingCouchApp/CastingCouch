# Creator Control Suite 3.3.3

## OBS Audio Mixer Pro – Profile

- Audio-Profile speichern Lautstärke, Mute, Monitoring und Synchronisierung aller steuerbaren OBS-Audioquellen.
- Vorhandene Profile können mit gleichem Namen aktualisiert werden.
- Profile können geladen und gelöscht werden.
- Nicht mehr vorhandene Quellen werden beim Laden übersprungen und verständlich gemeldet.
- Einstellungen werden dauerhaft in der Suite-Konfiguration gespeichert.
