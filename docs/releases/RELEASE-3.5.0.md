# Creator Control Suite 3.5.0 – Stream Automation Core

## Neu
- Direkte Trigger beim Streamstart und beim Aktivieren einer OBS-Szene
- Verzögerte Trigger seit Streamstart oder Szenenaktivierung bleiben erhalten
- OBS-Audioquellen automatisch laden und per Regel muten oder aktivieren
- OBS-Streaming per Automatisierungsregel starten oder stoppen
- Streamer.bot-Aktionen auswählen und aus einer Regel ausführen
- Bestehende Aktionen für Szenen, Quellen und Spotify bleiben kompatibel
- Regeltest weiterhin ohne automatischen Livegang; Start/Stop-Aktionen sollten bewusst getestet werden

## Hinweis
Ein vollständiger Windows/.NET-Build ist vor Veröffentlichung erforderlich.
