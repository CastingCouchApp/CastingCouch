# Creator Control Suite 3.8.0

## Automation Runtime Control

- Prioritäten für Automatisierungsregeln (-1000 bis 1000)
- Abarbeitung fälliger Regeln nach Priorität
- Ausführungsmodi: überspringen, neu starten oder parallel ausführen
- Konfigurierbares Timeout pro Regel
- Zentraler Abbruch laufender Automationen
- Laufzeitstatus im Automationseditor
- Diagnosemeldungen für Doppelstarts, Abbruch und Timeout
- Bestehende Regeln bleiben durch sichere Standardwerte kompatibel
