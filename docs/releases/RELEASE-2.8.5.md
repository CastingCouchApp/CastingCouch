# Creator Control Suite 2.8.6

## OBS-Quellen: Position und Größe

- Position (X/Y) und Ausgabegröße einer ausgewählten Szenenquelle direkt unter Dienste → OBS ändern.
- Eingaben werden vor dem Senden an OBS geprüft.
- Schnellvorlage für Vollbild 1920 × 1080.
- Schnellvorlage für 1280 × 720, zentriert auf einer 1920 × 1080-Leinwand.
- Transformationssteuerung bleibt deaktiviert, solange keine gültige Quelle ausgewählt ist.
- Vor jeder Änderung wird geprüft, ob die Quelle in der Szene noch existiert.
