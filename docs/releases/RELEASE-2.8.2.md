# Creator Control Suite 2.8.2

## OBS-Audiomixer

- Lautstärkeregler für die ausgewählte OBS-Audioquelle (-60 bis +10 dB).
- Direkte Synchronisierung zwischen Regler und dB-Eingabefeld.
- Schnellpegel für -20 dB, -10 dB und 0 dB.
- Mute/Unmute und Statusaktualisierung bleiben erhalten.
- Auswahl der Audioquelle bleibt beim OBS-Refresh erhalten.
- UI-Aktualisierungen lösen keine OBS-Schreibanfragen aus; ein Pegel wird erst mit „Pegel übernehmen“ oder einem Schnellpegel gesetzt.
