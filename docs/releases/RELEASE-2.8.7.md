# Creator Control Suite 2.9.0

## OBS-Quellenfilter

- Filter der ausgewählten OBS-Quelle direkt laden.
- Filtername, Typ, Reihenfolge und Aktivstatus anzeigen.
- Einzelne Filter aktivieren und deaktivieren.
- Auswahl bleibt bei einer Aktualisierung erhalten.
- Fehler werden in der OBS-Seite angezeigt und führen nicht zum Absturz.
- Manuelle Aktualisierung der Filterliste.
