# Creator Control Suite 2.8.4

## OBS-Quellenverwaltung

- Quellen einer Szene zeigen jetzt Sichtbarkeit, Sperrstatus und Ebenenindex.
- Quellen können direkt in der Suite gesperrt und entsperrt werden.
- Quellen können eine Ebene nach oben oder unten verschoben werden.
- Die Quellenauswahl bleibt nach jeder Aktion erhalten.
- Veraltete OBS-Quellen werden vor der Aktion erneut geprüft.
- Schaltflächen werden an den aktuellen Zustand und die mögliche Bewegungsrichtung angepasst.
