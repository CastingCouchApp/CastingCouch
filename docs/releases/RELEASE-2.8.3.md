# Creator Control Suite 2.8.3

## OBS-Übergangssteuerung

- OBS-Übergänge werden auf der OBS-Diensteseite direkt aus OBS geladen.
- Die aktuelle Auswahl bleibt bei einer manuellen Aktualisierung erhalten.
- Übergang und Dauer können gemeinsam übernommen werden.
- Die Dauer wird auf 0 bis 20.000 Millisekunden begrenzt.
- Fehler und Verbindungszustände werden direkt auf der Seite angezeigt.
- Beim Trennen von OBS werden Übergangsliste und Status sauber zurückgesetzt.

Diese Änderung startet oder beendet keinen Stream.
