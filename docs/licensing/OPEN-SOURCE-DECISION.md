# Open-Source-Entscheidung

Die kommerzielle Laufzeit-Lizenzierung wurde aus der Anwendung entfernt:

- keine Lizenzdateien oder Aktivierung,
- kein Lizenzserver oder Mockserver,
- keine Editionen oder Feature-Gates,
- keine lizenzabhängigen Themes oder Funktionen,
- kein Lizenzstatus in Diagnose, Installer-Selbsttest oder Release-Freigabe.

Alle enthaltenen Funktionen sind zur Laufzeit verfügbar.

Die Wahl einer konkreten Open-Source-Lizenz und die Prüfung der
Drittanbieter-Lizenzen sind eine separate rechtliche Entscheidung. Bis diese
Entscheidung getroffen und eine Root-`LICENSE` veröffentlicht ist, darf das
Repository nicht allein aufgrund dieser technischen Änderung als Open Source
bezeichnet werden.
