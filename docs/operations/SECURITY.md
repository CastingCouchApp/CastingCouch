# Sicherheit

- Passwörter und Client-Secrets werden nicht in settings.json gespeichert.
- Windows DPAPI schützt Secrets pro Windows-Benutzer.
- Logs dürfen keine Tokens oder Secrets enthalten.
- OAuth erfolgt erst nach der Installation.
- Crashberichte und Telemetrie sind später ausschließlich opt-in.
- Installer und Updates müssen für den Verkauf digital signiert werden.
